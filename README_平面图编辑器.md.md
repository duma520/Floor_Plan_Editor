# 房屋平面图编辑器 使用说明

## 简介
基于 Python + PySide6 开发的图形化房屋平面图设计工具，支持拖拽式操作，所见即所得。

## 环境要求
- Python 3.8+
- PySide6

## 安装依赖
```bash
pip install PySide6
```

## 运行方式
```bash
python floor_plan_editor.py
```

## 功能特性

### 🏠 房间模块
- **10种预设房间类型**：客厅、主卧、次卧、厨房、卫生间、阳台、餐厅、书房、走廊、储物间
- 每种房间有独特的配色和图标标识
- 支持自定义房间名称、填充颜色、边框颜色

### 🚪 门窗模块
- **门**：单开门、双开门、推拉门（带开启弧线示意）
- **窗**：普通窗、落地窗、飘窗
- 支持调整宽度、开启角度、旋转方向

### ⭐ 异形房间
- 支持多边形异形房间设计
- 拖动顶点自由调整形状
- 双击边可添加新顶点
- 选中顶点后可删除（至少保留3个顶点）

### ✏️ 编辑功能
- **移动**：选中后直接拖动
- **缩放**：选中后拖动8个控制点（四角+四边）
- **旋转**：右侧属性面板精确设置旋转角度
- **删除**：Delete键 或 属性面板删除按钮
- **网格吸附**：自动对齐到网格，方便精确布局

### 🔍 视图操作
- **缩放**：Ctrl + 鼠标滚轮
- **平移**：按住鼠标中键拖动
- **网格显示**：可开关网格背景
- **吸附功能**：可开关网格吸附

### 💾 文件操作
- 新建 / 打开 / 保存平面图（JSON格式）
- 导出为PNG/JPG图片
- 支持另存为

## 操作技巧

1. **添加房间**：从左侧模块库拖拽房间类型到画布
2. **添加门窗**：从左侧门窗列表拖拽到画布
3. **添加异形房**：点击"添加异形房间"按钮，然后拖动顶点调整
4. **精确调整**：选中对象后，在右侧属性面板输入精确数值
5. **批量选择**：按住鼠标左键框选多个对象
6. **快速删除**：选中后按Delete键

## 常见问题

**Q: 为什么拖拽模块到画布没反应？**
A: 请确保从左侧列表按住鼠标左键拖动到中央画布区域再松开。

**Q: 异形房间怎么添加顶点？**
A: 选中异形房间后，双击任意一条边，会在点击位置插入新顶点。

**Q: 可以调整画布大小吗？**
A: 画布默认为3000x2000像素，足够大部分户型使用，可通过平移和缩放查看不同区域。

**Q: 保存的文件可以再次编辑吗？**
A: 可以，保存的JSON文件可以通过"打开"功能重新加载继续编辑。
